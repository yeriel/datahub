# Organización del Conocimiento

Puedes estructurar tus notas utilizando carpetas y subcarpetas dentro de `content/docs/`.

## Recomendaciones

- **Temática clara**: Agrupa conceptos similares dentro de subdirectorios.
- **Nombres descriptivos**: Utiliza nombres de archivo en minúsculas y separados por guiones (ej. `mi-tema.md`).
- **Uso de MDX**: Si necesitas componentes interactivos o JSX, puedes usar la extensión `.mdx`.
