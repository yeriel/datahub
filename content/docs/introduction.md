# Bienvenido a DataHub

Este es tu espacio personal para organizar y gestionar conocimiento, notas de aprendizaje, documentación de proyectos y recursos.

## 🚀 Estructura inicial

- **Guías**: Manuales paso a paso y flujos de trabajo.
- **Notas**: Apuntes rápidos, resúmenes y conceptos.
- **Recursos**: Enlaces útiles, comandos y referencias.

## ✍️ Cómo añadir nuevo contenido

1. Crea un archivo `.md` o `.mdx` en la carpeta `content/docs/`.
2. Añade el encabezado YAML con `title` y `description`.
3. ¡Listo! El contenido se indexará automáticamente y estará disponible con búsqueda instantánea (`Cmd/Ctrl + K`).
